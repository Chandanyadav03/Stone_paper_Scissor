# Stone, Paper, Scissors - A Fun Web Game
This project is a simple yet engaging implementation of the classic Stone, Paper, Scissors game, built using HTML, CSS, and JavaScript. It offers an interactive and user-friendly interface for players to enjoy this timeless game directly in their web browser.

# Features:
Fully responsive design for seamless gameplay on different devices.
Real-time result display based on the player's choice and computer's random choice.
Interactive animations and styles to enhance user experience.
Clean and efficient JavaScript code for logic implementation.

# How to Play:
  1. Open the game in your browser.
  2. Select one option: Stone, Paper, or Scissors.
  3. The computer will randomly choose its option.
  4. The result will be displayed instantly – whether you win, lose, or it's a tie!

# Technologies Used:
 - HTML: For structuring the web page.
 - CSS: For styling the interface and adding visual effects.
 - JavaScript: For implementing the game logic and interactivity.
